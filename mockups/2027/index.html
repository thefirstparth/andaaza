On top of it I'd borrow two parts: B's history charts on cards (a month, a week, a day, to scale), which make "watch the world change its mind" literal, and C's "79% chance…" sentence as the plain line a first-time visitor reads first. On a phone, as an app

Yes, it installs, and that part is already built on the branch for the current site, separate from these mockups.

The home-screen icon: the page's own gauge drop, white on neel.

What it adds

  • A web app manifest and icons, so phones offer "Add to Home Screen" (iPhone) or "Install app" (Android). It opens full screen, like an app.
  • A small offline helper. The installed app opens without a connection and shows the last reading that phone kept.
  • The status bar takes the colour of the chosen look.

Why it stays care-free

  • The page always comes from the network first, so a new version is never held back. Readings are never stored by it.
  • Deleting one file (public/sw.js) removes the offline part; browsers drop it on their next check.
  • No push alerts. They would need a scheduled job and stored subscriptions, which breaks the first rule.
  • Checked in Chromium: installable, and it reopens offline with all seven gauges. Still to try on a real iPhone.
